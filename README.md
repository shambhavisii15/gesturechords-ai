# 🎸 AirStrum - AI Webcam Hand Gesture Chords

An interactive, browser-based AI tool that tracks webcam hand gestures in real-time to play musical chords. Powered by Computer Vision and Web Audio API.

---

## ✨ Features

- 🖐️ **Real-Time Hand Tracking:** Detects hand positions and gestures instantly via your webcam.
- 🎵 **Live Chord Generation:** Plays smooth audio chords (C Major, G Major, Am, F, etc.) based on hand movement.
- 🎥 **Visual Overlay:** Shows real-time skeletal hand landmarks and chord indicators directly on the video screen.
- ⚡ **Zero Installation:** Runs directly inside any modern web browser using client-side processing.

---

## 🛠️ Tech Stack

- **Computer Vision:** Google MediaPipe / Handpose API
- **Audio Processing:** Web Audio API / Tone.js
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Canvas Rendering:** HTML5 Canvas for real-time visual feedback
